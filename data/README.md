# Frozen execution inputs

`rules/` contains the Wizards rules effective 2026-09-25, with original-byte hash and source URL.

`cards/forge-20261010/` contains the 55 distinct engine scripts used by the Add/Halt and candidate constant boards. These are a pinned **Forge interpretation of card text**, not an independently certified Oracle snapshot. The provenance file records each original path, revision and byte hash. Official Oracle auditing remains required before making a current-rules certification claim.

`construction/types.json` supplies the current creature-type port. Capybara replaces historical Cephalid consistently; Octopus was rejected because the Output gadget uses it.

`construction/add-halt-prepared.json` is generated by `cargo run --quiet -- fixture`. The authored recipe is `src/construction.rs`; the generated JSON is a reviewable export, not a second implementation. It specifies prepared card properties, owners/controllers, counters, attachments, imprints, effects, timestamps and the cyclic program's initial rotation. It does not certify legal setup reachability.

The prepared fixture places Bludgeon Brawl after the lasting artifact changes. This is a deliberate timestamp variant: the paper defaults Brawl to its first timestamp group. Forge's type-change cache loses Equipment when Brawl's subtype grant is applied before the lasting Artifact change. A focused fixture verifies the artifact-first order. The full board must establish that this order preserves its other required interactions; this does not establish correctness of arbitrary duration-effect dependencies in Forge.

Stormtide Leviathan is assigned to Bob, so its own forced islandwalk attack faces Alice's Island and cannot corrupt the machinery through blocking. The paper leaves this global's controller unspecified. Before the reader opens the Y wildcard, Z gates lose their separate power-boost abilities to Blood Sun; inactive register power is one less than its stored counters. Decode register values from counters, and inspect effective power separately.

Schema3 includes chosen-color state and explicit ability-free tokens, in addition to explicit keyword-counter effect timestamps, copied Green reader bodies, White zero-mana Vehicle/Crew3 target Riders, and token Scythes. The source-protection Rider is a declared repair: a Croaking Counterpart 1/1 Green Frog copy, with Human→Saproling applied afterward to its rules text. A printed Human Rider would itself become a Saproling, suppress its own protection and disrupt Terrain’s Forest overwrite. Complete-board fixtures verify the repaired copy keeps a newly entered Forest as a noncreature Island. Fighter Reach and reader Double Strike counters precede Blood Sun. The candidate NumBuild extension retimes register survival/vigilance after Sun; its full execution is still under verification. `constants-prepared.json` is generated from `examples/constant-add.mtg`. See [preparation research](../docs/legal-setup.md).
